# Cadre photo

[Français](README.md) · [English](README.en.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Română](README.ro.md) · **Русский** · [العربية](README.ar.md) · [中文](README.zh.md)

**Превратите любой телевизор в семейную фоторамку с помощью Raspberry Pi за 20 €.**

Ваши фотографии показываются на весь экран, с плавными переходами, датой и местом съёмки.
Родные добавляют фотографии с телефона — без приложения и без учётной записи — или делятся ими
в общем альбоме iCloud, за которым рамка следит сама. Рамку можно установить у родственников и
забыть о ней: она подключается к Wi-Fi по QR-коду, управляется пультом телевизора и обновляется
удалённо.

## Что она умеет

[![Рамка на экране: воспоминание, место, время и погода](docs/images/ecran.jpg)](https://raw.githubusercontent.com/54yhbw7nfw-spec/cadre-photo/main/docs/images/ecran.jpg)

- **Слайд-шоу на весь экран**: растворение, сдвиг, шторка; вертикальные и горизонтальные фото
  аккуратно вписаны; дата, место (« Sallanches, France ») и воспоминания « 2 года назад ».
- **Фотографии с телефона**: отсканируйте QR-код на телевизоре, выберите фото — и всё. Перед
  отправкой фото уменьшаются: быстро даже при слабом Wi-Fi.
- **Общий альбом iCloud**: вставьте ссылку, рамка синхронизируется каждые 30 минут.
- **Без клавиатуры**: если знакомой сети нет, рамка создаёт свою сеть и показывает QR-код;
  домашний Wi-Fi выбирается с телефона.
- **Пульт телевизора** (HDMI-CEC): следующее и предыдущее фото, пауза, QR-код.
- **Сообщение на рамке** (« С днём рождения, бабушка! ») полосой или на весь экран, между двумя
  датами.
- **Время и погода**, ненавязчиво; ночной сон по расписанию (телевизор выключается и снова
  включается).
- **Избранное, скрытые фото, выбор того, что показывать** (альбом, загрузки, период).
- **Удалённое обновление** в два нажатия, подписанное вами, с автоматическим возвратом к прежней
  версии при проблеме; отчёт диагностики, который вам могут прислать.
- **9 языков**: страница управления и экраны рамки на французском, английском, испанском,
  немецком, португальском, румынском, русском, арабском и китайском.
- **Конфиденциальность**: всё хранится на рамке, учётная запись и онлайн-сервисы не нужны.

## Оборудование

| Компонент | Примечание |
|---|---|
| Raspberry Pi Zero W (или Zero 2 W) | Zero 2 W запускается примерно в 3 раза быстрее |
| Карта microSD на 16–32 ГБ | желательно класса A1 |
| Блок питания micro-USB 5 В, 2,5 А | хороший блок питания предотвращает сбои |
| Кабель или переходник mini-HDMI — HDMI | у Pi Zero разъём mini-HDMI |
| Телевизор или монитор с HDMI | HDMI-CEC (Anynet+, Simplink…) для пульта и режима сна |
| Компьютер для установки | Windows (Git Bash), macOS или Linux |

Бюджет: около 30 € без телевизора.

## Установка вкратце

1. **Подготовьте карту** в [Raspberry Pi Imager](https://www.raspberrypi.com/software/):
   Raspberry Pi OS Lite (32 бит), имя `cadre`, пользователь `cadre`, домашний Wi-Fi, SSH с вашим
   открытым ключом (он же служит для подписи обновлений).
2. **Установите рамку** с компьютера:
   ```bash
   git clone https://github.com/54yhbw7nfw-spec/cadre-photo.git
   cd cadre-photo
   ./install.sh cadre@cadre.local     # один раз спросит пароль пользователя
   ssh cadre@cadre.local sudo reboot
   ```
3. **Подключите к телевизору**: через полторы минуты QR-код откроет страницу управления.
   Добавьте фотографии — готово.

## Как это устроено

Python 3 (pygame / SDL2 в KMSDRM для изображения, Flask для страницы управления, Pillow для
фотографий), NetworkManager, systemd. Всё помещается в 512 МБ памяти на одноядерном процессоре
2017 года, с плавными переходами 60 кадров/с.
